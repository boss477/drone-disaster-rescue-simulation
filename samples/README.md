# Sample Images

- `test_cracked.jpg` is a clear cracked-concrete sample from the supplied project.
- `test_wall_texture.jpg` is a wall-texture image for pipeline testing. The supplied crack model scores it as ambiguous, so it is intentionally **not** labelled as a guaranteed clean-wall sample.

Capture your own exhibition samples with the Pi Camera and test them under the actual lighting. Do not select or tune samples from the model's validation set.
